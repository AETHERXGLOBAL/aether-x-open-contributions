# Security and responsible disclosure

This is a public technical portfolio, **not** a place for private vulnerability reports or company audit logs. Never publish credentials, keys, private emails, cloud account identifiers, local usernames/paths, unredacted logs, client details, unpublished exploits or private GitHub repository content.

For vulnerabilities affecting a named upstream project, use its private vulnerability-reporting or maintainer process. Use a public Issue here only for non-sensitive correction of public metadata.
