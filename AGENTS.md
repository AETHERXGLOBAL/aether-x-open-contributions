# AETHER X GLOBAL — Repository Agent Instructions

## AX-GITHUB-BRAND-IDENTITY-001 — AETHER X GLOBAL publishing identity (active on main)

For all new company GitHub-facing PRs, issues, commits, releases, comments and public docs, default to the organizational voice **AETHER X GLOBAL** (short **AETHER X**). Omit optional assistant/vendor-generated signatures, generator badges and tool co-author trailers from published drafts. **Never** misrepresent the real GitHub actor or author, impersonate a person, rewrite history, suppress mandatory notices or disclosures, alter tests/audit provenance, or claim human-only work without proof. Preserve upstream contribution rules, security/review/publication gates, licenses and truthful answers to provenance questions. Maintain detailed tool/evidence records internally when required. Public guidance: https://github.com/AETHERXGLOBAL/.github/pull/27 ; corporate operational decision: AETHERXGLOBAL/aether-x-governance PR #17. This repository-level adoption was merged in [PR #5](https://github.com/AETHERXGLOBAL/aether-x-open-contributions/pull/5). It grants no new permissions. External publication still requires target-specific approval and compliance with the upstream project's rules. Internal merges remain subject to the Founder-only exact-PR/HEAD authorization recorded in [Issue #9](https://github.com/AETHERXGLOBAL/aether-x-open-contributions/issues/9); repository settings alone cannot attest that authorization.

## AX-TEST-EVIDENCE-001 — Evidence-backed technical reporting (project adoption)

**Approved AETHER X GLOBAL policy:** https://github.com/AETHERXGLOBAL/aether-x-governance/blob/6986503e65d0f73e632bded50f68871eebd9229e/decisions/AX-TEST-EVIDENCE-001_GITHUB_TEST_EVIDENCE_DELIVERY_20261113.md. Material software/research/testing/QA/CI/security/adversarial reviews require the actual durable GitHub evidence bundle or sanitized index **mutually linked with the technical report**, identifying exact tested HEAD/tree, commands, exit codes, actual logs or machine-readable PASS/FAIL/SKIP/BLOCKED results, negative findings, SHA-256/size manifest, reproduction instructions, verified durable access and confidentiality controls. Never replace real evidence with a chat-only ZIP, summary-only document or expiring CI artifact; evidence missing ⇒ `EVIDENCE_PENDING / NOT READY FOR FINAL ACCEPTANCE OR MERGE`. Do not invent test success or suppress failures. For public or upstream contributions, **do not publish private company data, customer information, confidential logs, tokens, code or exploit data**. Keep restricted originals in a properly authorized private evidence store and publish a sanitized index/proof only when permitted and accurately labeled.

**No automatic propagation:** This applies only within this repository after project review/merge; the organization profile AGENTS.md cannot modify other repositories by itself. Existing legal, upstream license/maintainer requirements, project-specific security/independent reviews, Founder gates and STOPs remain in force. This is not an enabled CI required check or authorization to merge, deploy, spend, publish sensitive material or waive any project gate.
