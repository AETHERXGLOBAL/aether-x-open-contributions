# Maintenance and change control

This public portfolio is a curated projection of public source references, **not** a live synchronization system or replacement for private corporate audit records.

For updates: verify source links and original author → record source revision and outcome level → update unique JSON/CSV records → audit copyright, privacy and accidental disclosure → run the offline validator → review as a Pull Request. New observed dates should be new snapshots; do not overwrite the meaning of 2026-11-03 historical data.

Each new executable code candidate requires source SHA-256, exact upstream revision, positive and negative controls, actual test evidence and independent limitations. Published links are not endorsements. External GitHub replies, PRs, merges and public status upgrades remain separately authorized.


**Authoritative final-merge authority:** Founder only, exact PR and SHA, with documented approval per integration; no reviewer or AI process can authorize a merge. The currently deployed GitHub ruleset checks CI and merge shape but cannot attest this off-platform authorization. Review assistance from `ahmed363younis-dot` may remain `read`-only; do not grant `write` merely to imitate release authority. Keep any legally or project-mandated truly independent review.

**Current validations:** `python3 scripts/validate_catalog.py`, `python3 -O scripts/validate_catalog.py`, `python3 -m unittest discover -s scripts -p 'test_*.py' -v` and `python3 -O -m unittest discover -s scripts -p 'test_*.py' -v`. Runtime requirements no longer depend on Python `assert`; extensions include Python and GitHub workflows in the public-secret scanner. New participation uses `data/updates` and remains unqualified pending source review, not a retroactive rewrite of the immutable baseline.
